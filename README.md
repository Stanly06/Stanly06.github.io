## Publish on GitHub Pages

1. Back up the current repository.
2. Replace the old root files with `index.html`, `styles.css`, and `script.js` from this package.
3. Commit and push to the repository's `main` branch.
4. In GitHub, open **Settings → Pages** and confirm deployment from the `main` branch and `/root` folder.
5. Open `https://stanly06.github.io/` after the deployment finishes.
