# Stanly Fernández — BI & Data Portfolio

Single-file, dependency-free portfolio for GitHub Pages (`index.html`). Sections: About, Experience, Certifications, Projects (Databricks, SQL, Power BI, Python filters), Skills, Knowledge sharing, Contact.

Features: light/dark theme, project filters with cursor spotlight, interactive Medallion (Bronze/Silver/Gold) diagram, animated SQL terminal, typed roles, counters, Ctrl+K quick navigation, reduced-motion support.

## Publish
1. Copy `index.html` and `404.html` to the root of `Stanly06/Stanly06.github.io` (replace the old `index.html`, `styles.css`, `script.js`).
2. Commit and push to `main`.
3. Settings → Pages → deploy from `main` / root.
